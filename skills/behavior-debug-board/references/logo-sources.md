# Logo sources and usage

## Bundled service logos

| File | Product | Source | Variant | License / usage |
|---|---|---|---|---|
| `assets/logos/firebase.svg` | Firebase | `https://thesvg.org/icon/firebase` | `default` | theSVG lists CC0-1.0; Firebase trademark rules still apply |
| `assets/logos/firestore.svg` | Cloud Firestore | `https://thesvg.org/icon/firestore` | `default` | theSVG lists Custom; use only to identify Cloud Firestore |

The copies rendered by the app live under `public/logos/` and match these upstream SVGs.

Firebase's official guidelines prefer the full-color mark, require at least 24px height, prohibit recoloring/distortion, and prohibit implying endorsement: `https://firebase.google.com/brand-guidelines`.

## Generic UI icons

Pointer, hand, zoom, play, pause, replay, note, text, shape, move, status, and other non-brand icons come from `lucide-static` (Lucide, ISC license). These are UI symbols, not service logos.

## Trademark rule

Code in this repository may use the MIT license. Brand marks remain trademarks of their owners and are not relicensed by the project. Keep them subordinate to the service label and use them only for identification.
